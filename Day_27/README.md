## Key concepts

**Database:** A place where data can be stored, retrieved, updated, and deleted.

**SQL:** Structured Query Language used to interact with relational databases.

**PostgreSQL:** An open-source relational database management system that uses SQL.

**Table:** Organizes data into rows and columns.

**Row:** Represents one record.

**Column:** Represents a specific type of information.

**Relational database:** A database where tables can have relationships with each other.

## Example SQL

```sql
SELECT name FROM users;
```

This selects the `name` column from the `users` table.
